## 项目背景
数据底座平台。为前面所有C端和B端系统提供高质量数据支撑。核心流程：数据采集 → 自动清洗去重 → AI辅助标注 → 版本化管理 → 质量报告。

## 技术框架
- 前端: Vue3 + TypeScript + NaiveUI + Pinia + Vite
- 后端: Python FastAPI + SQLAlchemy 2.0 (async)
- 数据引擎: DVC (版本控制) + Cleanlab (质量检测) + Argilla (标注)
- 存储: PostgreSQL + MinIO
- 部署: Docker Compose + Nginx

## 关键变化（全新增模块）
