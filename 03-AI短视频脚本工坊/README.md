# 项目③ — AI短视频脚本工坊

## 🎯 项目目标
短视频自动化生产引擎:
- 分镜脚本（镜号/时长/画面/口播/字幕）
- 口播话术（钩子/卖点/CTA）
- 拍摄建议（B-roll/转场/字幕样式）
- AI配音（Edge-TTS 神经网络语音，免费无限制）
- AI视频生成（智谱 CogVideoX-2）
- 字幕导出（SRT/ASS，支持逐镜精确对齐）

## 🏗️ 技术框架
Vue3 + FastAPI + LangChain + DeepSeek + SQLite/PostgreSQL + ChromaDB + Edge-TTS + 智谱 CogVideoX
