## 项目背景
企业销售角色扮演培训平台。业务场景：保险公司培训新人。AI扮演不同类型的挑剔客户（"太贵了""别家更便宜"），销售练习应对话术。AI实时多维度打分：流畅度/说服力/产品知识准确性/异议处理能力。

## 技术框架
- 前端: Vue3 + TypeScript + NaiveUI + Pinia + Vite
- 后端: Python FastAPI + SQLAlchemy 2.0 (async)
- AI: LangChain + DeepSeek + LangGraph (多轮对话状态机) + RAG (产品知识库)
- 数据: PostgreSQL (生产) / SQLite (开发)
