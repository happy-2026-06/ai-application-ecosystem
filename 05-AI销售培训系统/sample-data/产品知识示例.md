# 产品知识示例 — 智能手表

## 产品概述
品牌：TechFit Pro
型号：HealthGuard X1 智能手表
定位：中高端健康监测智能手表
售价：¥3,999

## 核心卖点

### 1. 健康监测
- 医疗级心率传感器：精度±2bpm，24小时连续监测
- 血氧饱和度监测：红外光+红光双波段，准确度98.5%
- 睡眠分析：深睡/浅睡/REM 分阶段监测
- ECG心电图：30秒快速检测，FDA认证

### 2. 超长续航
- 日常使用：7天（全天心率+通知）
- 省电模式：14天
- 快充：充电15分钟，使用1天

### 3. 运动模式
- 支持100+运动模式
- GPS+GLONASS双星定位
- 50米防水
- 自动运动识别（跑步/游泳/骑行）

### 4. 智能功能
- 1.43英寸 AMOLED屏幕，1000nit亮度
- 蓝牙通话+独立音乐播放
- NFC门禁卡+支付宝离线支付
- 消息通知（微信/短信/来电）

## 常见客户问题

**Q: 心率监测准吗？**
A: 采用医疗级PPG传感器，精度±2bpm。和医院心电图对比测试，准确率达到98.5%。

**Q: 电池能用多久？**
A: 正常使用7天，比Apple Watch的18小时长了9倍。充电15分钟就能用一天。

**Q: 和苹果手表比怎么样？**
A: 我们比苹果便宜2500元，续航长9倍，ECG功能一样有FDA认证。如果你用的是安卓手机，我们兼容性更好。

**Q: 能戴着游泳吗？**
A: 可以！50米防水，游泳戴着完全没问题。自动识别游泳模式，记录圈数、距离、卡路里。
