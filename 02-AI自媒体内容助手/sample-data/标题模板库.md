# 标题模板库

## 使用说明
每个标题模板中的 `{占位符}` 需要替换为实际内容：
- `{产品}` — 你的具体产品名（如"XX充电宝"）
- `{品类}` — 产品所属类别（如"充电宝"、"蓝牙耳机"）
- `{竞品}` — 竞品品牌名
- `{数字}` — 具体数字（建议 3/5/7/10）
- `{场景}` — 使用场景（通勤/健身/居家/办公）
- `{人群}` — 目标用户（学生党/上班族/宝妈）
- `{痛点}` — 用户痛点描述
- `{价格}` — 具体价格
- `{品牌}` — 品牌名称

## 通用标题公式总结

1. **反常识法**: "千万别买{产品}，除非..." — 标题否定，内容推荐
2. **数字锚定法**: "{数字}个{品类}..." — 数字降低认知负担
3. **痛点共鸣法**: "{痛点}？这个方法救了命" — 痛点在前，方案在后
4. **人群锁定法**: "{人群}必看！..." — 精准筛选目标用户
5. **价格反差法**: "只要{价格}，效果不输{高价}" — 性价比冲击
6. **悬念揭秘法**: "90%的人不知道的{品类}真相" — 信息不对称
7. **时间效应法**: "用了{时间}，{效果}" — 真实体验增加信任
8. **对比冲突法**: "{便宜} vs {贵}" — 对比创造认知冲突
