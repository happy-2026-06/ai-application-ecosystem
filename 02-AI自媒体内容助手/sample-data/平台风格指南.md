# 五大平台风格指南

## 一、抖音 (Douyin)

### 平台特征
- **用户画像**: 18-35岁为主，下沉市场覆盖广，男女比例均衡
- **内容调性**: 快节奏、强情绪、反常识、口语化
- **推荐时长**: 15-60秒（带货类30-45秒最佳）
- **算法特点**: 完播率 > 互动率 > 转粉率，前3秒决定生死

### 内容风格
- 开头必须"钩子"：反常识、悬念、痛点直击
- 口语化表达："家人们"、"咱们就是说"、"谁懂啊"
- 节奏快，信息密度高，3秒一个刺激点
- 善用对比、反差、挑战类内容
- BGM很重要，选热门卡点音乐

### 最佳发布时间
| 时段 | 推荐指数 | 说明 |
|------|---------|------|
| 07:00-09:00 | ★★★★☆ | 通勤高峰，碎片时间 |
| 12:00-14:00 | ★★★★★ | 午休黄金档 |
| 18:00-20:00 | ★★★★☆ | 下班通勤 |
| 21:00-23:00 | ★★★★★ | 睡前流量高峰 |

### Hashtag策略
- 必选: 1-2个热门大词 (#好物推荐 #种草)
- 精准: 2-3个品类词 (#充电宝推荐 #数码好物)
- 自创: 1个品牌/系列标签 (#XX品牌日)
- 数量: 3-6个为宜，过多被限流

### 封面设计要点
- 大字标题（占画面30%-40%）
- 高对比度配色（黄底黑字 / 红底白字）
- 人物表情夸张（惊呀、夸张）
- 产品/核心卖点清晰可见

### 爆款公式
- **AIDA公式**: Attention(注意) → Interest(兴趣) → Desire(欲望) → Action(行动)
- **悬念反转**: 先说反面/反常识结论 → 引发好奇 → 揭晓真相
- **痛点解决**: 描述痛点场景 → 放大痛苦 → 给出解决方案
- **"千万别买"体**: 标题否定 → 内容实则强烈推荐

## 二、小红书 (Xiaohongshu)

### 平台特征
- **用户画像**: 18-35岁女性为主（70%+），一二线城市
- **内容调性**: 精致、种草、真实分享感、高审美
- **推荐形式**: 图文笔记 + 短视频（3分钟内）
- **算法特点**: 封面点击率 > 收藏率 > 互动率

### 内容风格
- "真实体验感"是核心，避免硬广感
- 精致排版，emoji丰富但不浮夸
- 标题要"好物感"："亲测"、"好用到哭"、"闭眼入"
- 正文结构化：分点列出，用emoji做视觉引导
- 图片/视频高颜值，统一滤镜风格
- 善用"测评"、"对比"、"合集"形式

### 最佳发布时间
| 时段 | 推荐指数 | 说明 |
|------|---------|------|
| 07:30-09:00 | ★★★★☆ | 起床刷手机 |
| 12:00-14:00 | ★★★★★ | 午休种草时间 |
| 16:00-18:00 | ★★★★☆ | 下午摸鱼 |
| 20:00-23:00 | ★★★★★ | 睡前深度浏览 |

### Hashtag策略
- 品类词: 2-3个 (#蓝牙耳机 #降噪耳机)
- 场景词: 1-2个 (#通勤好物 #健身装备)
- 人群词: 1个 (#学生党 #上班族)
- 品牌词: 可选1个
- 数量: 5-8个，不要超过10个

### 封面设计要点
- 高颜值产品图/场景图
- 柔和色调，避免过于饱和
- 文字标签精致小巧（花字/贴纸风）
- 统一竖版3:4比例
- 善用拼图/对比图

### 爆款公式
- **SCQA公式**: Situation(情境) → Complication(冲突) → Question(问题) → Answer(答案)
- **测评种草**: 多款产品横向对比 → 真实使用感受 → 红黑榜总结
- **省钱攻略**: 低价替代方案 → 性价比分析 → 购买渠道
- **隐藏用法**: 常见产品的"你不知道的用法"

## 三、B站 (Bilibili)

### 平台特征
- **用户画像**: 16-30岁，Z世代为主，男性略多
- **内容调性**: 硬核、有料、深度、真实
- **推荐时长**: 3-15分钟（深度内容 > 短平快）
- **算法特点**: 三连(点赞+投币+收藏)权重极高，弹幕互动加分

### 内容风格
- "有干货"是硬道理，数据、对比、深度分析
- 可以长，但不能水
- 弹幕文化：善用梗、造梗、互动
- 分章节/时间戳标注
- 字幕动画增强趣味性
- "省流助手"式的开头总结受欢迎

### 最佳发布时间
| 时段 | 推荐指数 | 说明 |
|------|---------|------|
| 12:00-14:00 | ★★★★☆ | 午休 |
| 17:00-19:00 | ★★★★☆ | 放学/下班 |
| 20:00-22:00 | ★★★★★ | 晚间黄金档 |
| 周末10:00-12:00 | ★★★★★ | 周末闲暇 |

### Hashtag策略
- 分类标签: 必选 (#数码 #测评 #科技)
- 品牌标签: 1个
- 话题标签: 参与热门话题
- 数量: 3-5个，宁缺毋滥

### 封面设计要点
- 大字标题 + 产品图 + UP主表情
- 文字一般用白字+描边/阴影
- 信息量可以大一些
- 比例16:9横版
- 色彩鲜明，有视觉冲击力

### 爆款公式
- **深度测评**: 开箱 → 参数对比 → 实测数据 → 优缺点 → 购买建议
- **"我用XX台告诉你答案"**: 多款横评，终极选购指南
- **知识科普**: 原理讲解 + 选购技巧 + 行业内幕
- **"值不值"系列**: 性价比深度分析，消费决策参考

## 四、视频号 (WeChat Video)

### 平台特征
- **用户画像**: 30-50岁为主，中产家庭，微信生态用户
- **内容调性**: 温和、走心、品质感、生活化
- **推荐时长**: 1-3分钟
- **算法特点**: 社交推荐(朋友点赞) > 算法推荐

### 内容风格
- 温和叙述，不制造焦虑
- 强调"品质生活"、"效率提升"
- 故事化表达："那天我发现…"
- 适合知识分享、生活技巧、好物推荐
- 避免过于夸张或负能量
- 封面图优雅简洁

### 最佳发布时间
| 时段 | 推荐指数 | 说明 |
|------|---------|------|
| 07:00-08:00 | ★★★★☆ | 早起族 |
| 11:30-13:00 | ★★★★★ | 午间休息 |
| 18:00-19:00 | ★★★★☆ | 晚餐前后 |
| 21:00-22:00 | ★★★★★ | 睡前放松 |

### Hashtag策略
- 定位标签: 1-2个 (#品质生活 #好物分享)
- 品类标签: 1-2个
- 数量: 2-4个，简约克制

### 封面设计要点
- 干净简约风格
- 文字简洁大气
- 色彩柔和温暖
- 生活场景图为主
- 竖版为主，1:1或9:16

### 爆款公式
- **品质提升**: 一个生活痛点 → 产品如何提升体验 → 真实改变
- **故事叙述**: 个人经历引入 → 发现产品 → 使用感受 → 推荐
- **知识分享**: 行业知识/技巧 → 产品作为解决方案自然带出

## 五、快手 (Kuaishou)

### 平台特征
- **用户画像**: 25-45岁，下沉市场占比较高
- **内容调性**: 接地气、真实、实在、信任感
- **推荐时长**: 30-90秒
- **算法特点**: 普惠流量分配，粉丝粘性高

### 内容风格
- "老铁"文化，强社交信任感
- 语言朴实，像跟朋友聊天
- 注重真实感：工厂实拍、使用过程、真人出镜
- "实在"是核心价值主张
- 善用方言、口头禅增加亲切感
- 结尾引导互动（"觉得有用双击关注"）

### 最佳发布时间
| 时段 | 推荐指数 | 说明 |
|------|---------|------|
| 06:00-08:00 | ★★★★☆ | 早起用户 |
| 12:00-14:00 | ★★★★★ | 午休时间 |
| 18:00-20:00 | ★★★★★ | 下班高峰 |
| 21:00-22:00 | ★★★★☆ | 晚间休闲 |

### Hashtag策略
- 热门标签: 1-2个
- 品类标签: 2-3个
- 地域标签: 可选
- 数量: 3-5个

### 封面设计要点
- 产品实物图为主
- 文字直接、有冲击力
- 颜色鲜艳，高对比度
- 可加价格/优惠信息
- 人物表情自然真实

### 爆款公式
- **PAS公式**: Problem(问题) → Agitate(放大痛点) → Solve(解决)
- **省钱攻略**: 这个价格买到这个品质，老铁们冲
- **实测实拍**: 真机上手，不吹不黑
- **对比种草**: 便宜 vs 贵的，差距到底在哪

## 跨平台通用内容策略

### 一鱼多吃（内容复用）
1. **长视频(B站)** → 拆分为 **短视频片段(抖音/快手)** → 提取 **金句图文(小红书)**
2. **图文笔记(小红书)** → 扩展为 **视频脚本(抖音/B站)** → 提炼 **口播文案(快手)**

### 标题关键词公式
- **数字 + 结果**: "3天用了这款充电宝，再也没带过充电线"
- **疑问 + 解决方案**: "手机没电焦虑？这个20000mAh的充电宝救了我"
- **对比 + 推荐**: "比某米便宜一半，这个充电宝才是性价比之王"

### 算法友好度提升技巧
1. **完播率**: 前3秒必须抛出钩子
2. **互动率**: 视频中设置互动点（"你觉得呢？评论区告诉我"）
3. **收藏率**: 提供"收藏级"干货内容
4. **转粉率**: 结尾引导关注 + 内容系列化
