# 短视频脚本模板库

## 带货类（抖音/快手风格）

### 痛点前置型
```
[黄金3秒] {痛点场景}，你还在{错误做法}？
[痛点挖掘] 很多{目标人群}都会遇到…
[产品引入] 直到我发现{产品名}
[卖点123] 每个卖点配合使用场景
  - 卖点1：{功能} + {场景} = {效果}
  - 卖点2：{功能} + {场景} = {效果}
  - 卖点3：{功能} + {场景} = {效果}
[价格锚点] 原价{高价格}，今天{低价格}
[行动号召] 点击下方链接/评论区置顶…
```

### 对比测评型
```
[开场] {产品A} vs {产品B}，到底选哪个？
[外观对比] 左边{产品A}，右边{产品B}…
[参数对比] 3-5个关键差异表格
[实际体验] 7天后我发现…
[结论] 如果你{场景A}，选{产品A}；如果你{场景B}，选{产品B}
```

### 开箱种草型
```
[悬念] 猜猜这个{小东西}能干嘛？
[开箱过程] 包装 → 外观 → 配件 → 第一印象
[功能演示] 最让我惊喜的是…
[使用场景] 早上醒来…中午休息…晚上回家…
[总结推荐] 真心推荐给{目标人群}
```

## 口播类脚本结构

### 知识科普类
```
[钩子] 90%的人不知道的{领域}真相
[错误认知] 列出常见的3个错误做法/想法
[科学解释] 简单易懂的原理说明
[正确做法] Step by step
[延伸建议] 额外 tips
[互动引导] 你觉得呢？评论区聊聊
```

## 平台适配规则
| 平台 | 时长 | 风格 | 特殊要求 |
|------|:--:|------|---------|
| 抖音 | 30-60s | 口语化/快节奏 | 前3秒必须抓人 |
| 小红书 | 不限 | 精致/种草 | 封面图+Tag重要 |
| 视频号 | 60-180s | 温和/走心 | 正能量优先 |
| B站 | 2-10min | 有趣/深度 | 弹幕互动文化 |
| 快手 | 30-60s | 接地气/实在 | 老铁文化 |
