# 项目② — 灵笔内容引擎

## 🎯 项目目标
AI爆款内容生成工具。用户输入话题 → AI 生成：
- 爆款标题（5平台适配：抖音/小红书/B站/视频号/快手）
- 短视频脚本（带货/种草/测评）
- 图文文案 + Tag
- 发布建议（最佳时间/拍摄建议/互动话术）

## 🏗️ 技术框架
Vue3 + FastAPI + LangChain + DeepSeek + SQLite/PostgreSQL

## 📄 状态: 🟢 核心功能已完成 (v1.0)
