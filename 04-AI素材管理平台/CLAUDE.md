## 项目背景
企业数字资产管理平台。业务场景：设计公司有上万张图片/视频素材。上传后AI自动打标签（"红色跑车""蓝天海滩"），设计师输入"夕阳下的城市"就能搜到相关素材。支持文搜图/图搜图。还有版本管理和权限控制。

## 技术框架
- 前端: Vue3 + TypeScript + NaiveUI + Pinia + Vite
- 后端: Python FastAPI + SQLAlchemy 2.0 (async)
- AI: LangChain + DeepSeek + CLIP/BLIP (图像理解) + ChromaDB (多模态向量)
- 存储: MinIO (对象存储)
- 数据: PostgreSQL (生产) / SQLite (开发)

## 关键变化（相比项目①）
- 新增素材表 + 标签表 + 权限表
- AI能力从纯文本RAG → 多模态（图片+视频理解）
- 存储从本地文件 → 对象存储
- 新增多角色权限（超级管理员/编辑者/查看者）
